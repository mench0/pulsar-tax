# Pulsar Tax

Помощник ИП в Армении: налоги, порог оборота, доходы и счета.

Первый продукт экосистемы **Pulsar**. MVP для проверки спроса.

## Что умеет

- **Обзор:** доход и налог за год, налог по кварталам, сколько осталось до порога режима
  (24 млн ֏ у микробизнеса, 115 млн ֏ у налога с оборота), предупреждение с 80% порога.
- **Ближайшие сроки:** уплата налога с оборота до 20-го числа после квартала,
  выбор режима до 20 февраля.
- **Доходы:** учёт поступлений по датам.
- **Счета:** создание счёта с позициями, автономер `PT-2026-001`, печать и сохранение в PDF,
  отметка оплаты (доход записывается сам).
- **Настройки:** реквизиты ИП, режим, вид деятельности, своя ставка.
  Проверка, может ли вид деятельности применять выбранный режим.

## Запуск

Нужна только **Java 21+**. Внешних библиотек нет.

```bash
./build.sh          # собрать build/pulsar-tax.jar
./build.sh test     # собрать и прогнать тесты
java -jar build/pulsar-tax.jar
```

Откройте http://127.0.0.1:8080

### Windows (PowerShell)

```powershell
mkdir build\classes -Force
javac --release 21 -encoding UTF-8 -d build\classes (Get-ChildItem -Recurse src\main\java -Filter *.java).FullName
Copy-Item -Recurse -Force src\main\resources\* build\classes\
jar --create --file build\pulsar-tax.jar --main-class am.pulsar.tax.Main -C build\classes .
java -jar build\pulsar-tax.jar
```

### Настройки через переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PULSAR_PORT` | `8080` | Порт |
| `PULSAR_HOST` | `127.0.0.1` | Адрес. `0.0.0.0` откроет доступ из сети |
| `PULSAR_DATA` | `data/pulsar.json` | Файл с данными |

Данные хранятся в одном JSON-файле. Для резервной копии достаточно скопировать его.

## Устройство

```
src/main/java/am/pulsar/tax/
  Main.java        точка входа
  Server.java      HTTP-сервер (JDK HttpServer): REST API и статика
  Store.java       хранилище в JSON-файле с атомарной записью
  TaxRules.java    налоговые правила: пороги, ставки, расчёт
  Summary.java     годовая сводка, кварталы, сроки, предупреждения
  Codec.java       разбор и проверка входящих данных
  Fields.java      чтение полей с понятными ошибками
  Json.java        минимальный JSON без зависимостей
  Model.java       модель: профиль, доход, счёт
src/main/resources/web/
  index.html, styles.css, app.js   фронтенд без сборки
src/test/java/am/pulsar/tax/AllTests.java   тесты (без JUnit)
```

### API

| Метод | Путь | Описание |
|---|---|---|
| GET / PUT | `/api/profile` | Профиль ИП |
| GET | `/api/rules?year=2026` | Пороги, ставки и доступные режимы по видам деятельности |
| GET | `/api/summary?year=2026` | Сводка за год |
| GET / POST | `/api/incomes?year=2026` | Доходы |
| DELETE | `/api/incomes/{id}` | Удалить доход |
| GET / POST | `/api/invoices` | Счета |
| GET / DELETE | `/api/invoices/{id}` | Счёт |
| POST | `/api/invoices/{id}/paid?date=2026-08-03` | Отметить оплату |

Ошибки возвращаются как `{"error": "текст"}`. Тела запросов — только `Content-Type: application/json`.
Изменяющие запросы с чужим `Origin` и (при запуске на 127.0.0.1) запросы с чужим `Host` отклоняются с кодом 403.

## Важно про налоги

Пороги, ставки и ограничения по видам деятельности (`TaxRules.java`) хранятся по годам
и взяты из открытых обзоров на 2026 год: микробизнес до 24 млн ֏, налог с оборота до 115 млн ֏,
ставка 10% для торговли и услуг, 1% для компаний из реестра High-Tech. Микробизнес недоступен
консультациям, юридическим и бухгалтерским услугам, инжинирингу, рекламе, дизайну и переводу;
налог с оборота — юридическим, бухгалтерским услугам и агентской деятельности.
Новый год правил добавляется одной записью `YearRules` в `TaxRules`. **Перед работой с клиентами сверьте их
с Налоговым кодексом РА и бухгалтером.** Общая система (НДС) в MVP не рассчитывается.
